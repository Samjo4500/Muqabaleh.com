BUSINESS MODEL
═══════════════════════════════════════════════════════════════════════════════

Two-sided marketplace: Candidates book live mock interviews with real HR 
professionals. Platform takes commission on every booking.

│ Tier        │ Candidate Pays│ Interviewer Gets │ You Keep │

│ Pro         │ $49           │ $39.20           │ $9.80    │
│ Executive   │ $99           │ $79.20           │ $19.80   │
└─────────────┴──────────────┴──────────────────┴──────────┘

Loyalty bonus:
• 10+ completed sessions → interviewer keeps +5% (platform fee drops to 15%)
• 50+ completed sessions → interviewer keeps +10% (platform fee drops to 10%)

Payout schedule: Every 2 weeks (biweekly) via PayPal

8. DATABASE SCHEMA (Add to Prisma)
═══════════════════════════════════════════════════════════════════════════════

model Interviewer {
  id              String   @id @default(uuid())
  userId          String   @unique
  user            User     @relation(fields: [userId], references: [id])
  status          String   @default("PENDING") // PENDING, APPROVED, REJECTED, SUSPENDED
  fullName        String
  fullNameAr      String?
  bio             String?  @db.Text
  bioAr           String?  @db.Text
  linkedInUrl     String?
  phone           String?
  yearsExperience Int
  specialties     String[] // Role slugs
  industries      String[] // Industry slugs
  languages       String[] // AR, EN, FR
  priceTier       String   @default("STANDARD") // STANDARD, PRO, EXECUTIVE
  hourlyRate      Int      // in cents (e.g., 2900 for $29)
  rating          Float    @default(0)
  totalInterviews Int      @default(0)
  totalEarnings   Int      @default(0) // cents earned lifetime
  videoIntroUrl   String?
  idDocumentUrl   String?
  idVerified      Boolean  @default(false)
  payoutEmail     String?
  payoutMethod    String   @default("PAYPAL") // PAYPAL, BANK
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt
  
  availability    InterviewerAvailability[]
  bookings        HumanBooking[] @relation("InterviewerBookings")
  payouts         InterviewerPayout[]
  reviews         InterviewerReview[]
}

model InterviewerAvailability {
  id            String    @id @default(uuid())
  interviewerId String
  interviewer   Interviewer @relation(fields: [interviewerId], references: [id], onDelete: Cascade)
  dayOfWeek     Int       // 0=Sunday, 1=Monday...6=Saturday
  startTime     String    // "09:00" in 24h format
  endTime       String    // "17:00"
  isAvailable   Boolean   @default(true)
  createdAt     DateTime  @default(now())
  
  @@index([interviewerId])
}

model HumanBooking {
  id                String   @id @default(uuid())
  candidateId       String
  candidate         User     @relation("CandidateBookings", fields: [candidateId], references: [id])
  interviewerId     String
  interviewer       Interviewer @relation("InterviewerBookings", fields: [interviewerId], references: [id])
  status            String   @default("PENDING") // PENDING, CONFIRMED, COMPLETED, CANCELLED, NO_SHOW, DISPUTED
  scheduledAt       DateTime
  durationMinutes   Int      @default(30)
  priceTotal        Int      // cents (what candidate paid)
  platformFee       Int      // cents (20%, 15%, or 10%)
  interviewerPayout Int      // cents
  provider          String   @default("JITSI") // JITSI, ZOOM
  meetingLink       String?
  hostLink          String?  // for Zoom start_url
  recordingUrl      String?
  candidateNote     String?  @db.Text
  interviewerNotes  String?  @db.Text
  candidateFeedback String?  @db.Text
  candidateRating   Int?
  interviewerRating Int?
  disputeReason     String?
  cancelledBy       String?  // CANDIDATE, INTERVIEWER, PLATFORM
  cancelledAt       DateTime?
  createdAt         DateTime @default(now())
  updatedAt         DateTime @updatedAt
  
  @@index([candidateId])
  @@index([interviewerId])
  @@index([status])
}

model InterviewerPayout {
  id                  String   @id @default(uuid())
  interviewerId       String
  interviewer         Interviewer @relation(fields: [interviewerId], references: [id])
  amount              Int      // cents
  status              String   @default("PENDING") // PENDING, PAID, FAILED
  paidAt              DateTime?
  paypalTransactionId String?
  periodStart         DateTime
  periodEnd           DateTime
  createdAt           DateTime @default(now())
  
  @@index([interviewerId])
  @@index([status])
}

model InterviewerReview {
  id            String   @id @default(uuid())
  bookingId     String   @unique
  booking       HumanBooking @relation(fields: [bookingId], references: [id])
  reviewerId    String   // User who left review (candidate)
  rating        Int      // 1-5
  comment       String?  @db.Text
  isPublic      Boolean  @default(true)
  createdAt     DateTime @default(now())
}

9. VIDEO CALL INFRASTRUCTURE
═══════════════════════════════════════════════════════════════════════════════

PHASE 1 (MVP — Implement Now): Jitsi Meet (Free)
• No API key required
• Generate URL: https://meet.jit.si/muqabaleh-{bookingId}-{randomString(6)}
• Store in HumanBooking.meetingLink
• Send to candidate + interviewer in confirmation email
• Works in browser, no download needed
• 100 participant limit, 60-minute limit (fine for 1-on-1)

PHASE 2 (Scale — Later): Zoom API
• Zoom Pro account ($14.99/month)
• Server-to-Server OAuth app
• API: POST /v2/users/me/meetings
• Settings: host_video=true, participant_video=true, waiting_room=true, 
  auto_recording="cloud", join_before_host=false
• Webhook: meeting.ended → store recording URL
• Store hostLink (start_url) for interviewer

Provider selection:
• Default: JITSI for all bookings
• Admin can toggle individual bookings to Zoom
• Executive tier ($99) auto-uses Zoom when available
